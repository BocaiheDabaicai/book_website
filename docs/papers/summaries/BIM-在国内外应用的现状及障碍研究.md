# BIM 在国内外应用的现状及障碍研究

> 阅读日期：2026-08-06 | 作者：何清华，钱丽丽，段运峰，李永奎 | 年份：2012 | 期刊：工程管理学报

## 研究场景

BIM现状

## 核心问题

BIM 将成下一代主流技术，但推广应用大环境尚不成熟；项目运作缺少统筹管理，BIM 应用遭遇“协同”困境。BIM 理念贯穿项目全寿命期，但各阶段缺乏有效管理集成。大规模运用到建筑业，亟需推行 BIM 综合应用模式。

## 研究结论与实践价值

系统研究 BIM 国内外应用现状及软件交互性，探讨其发展动态及存在的障碍，对提高综合集成管理质量和水平具有重要理
论和现实意义；同时也将进一步促进 BIM 的深入推广并使其价值最大化，为 BIM 在我国的广泛应用起到重要基础研究作用和价值。
