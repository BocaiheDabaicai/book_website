# 基于 DEMATEL-ISM 和演化博弈的工程咨询企业数字化转型影响因素研究

> 阅读日期：2026-08-06 | 作者：戚振强，石金莲，胡博瑞 | 年份：2025 | 期刊：工程管理学报

## 研究场景

工程咨询企业的数字化转型

## 核心问题

没有相关的工程咨询企业数字化转型的影响因素分析

## 研究方法

问卷调查、假设法

## 核心变量 / 评价指标

领导层数字素养、企业数字化动态能力、数字化应用技术及迭代程度、经营效益、政策引导和激励因素

## 研究结论与实践价值

有助于企业在数字化转型阶段，丰富和完善自身的相关理论体系

## 研究局限

数据样本偏少，仅通过26篇文献分析、访谈10名专家进行论文分析

## 可借鉴内容

数据来源可以从文献网站、访谈来进行获取
